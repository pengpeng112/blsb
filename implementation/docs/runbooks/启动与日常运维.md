2. 分别启动：`python -m uvicorn apps.core_api.app:get_app --port 8000`、
   `python -m uvicorn apps.storage_service.app:get_app --port 8001`、
   `python -m uvicorn apps.exchange_gateway.app:get_app --port 8002`、

3. 首次执行 `python -m apps.seed`（或按医院重写种子：真实租户/来源/卷/阻断清单）。

## 监控要点（07 §6，控制台「总览/设备采集/外部阻断」已展示）
- 设备离线（>5分钟无心跳 → 告警页 AGENT_OFFLINE）。
- 最老待处理任务时长（总览 `oldest_pending_job_age_seconds`）。
- 磁盘：存储管理页（空闲/预留/安全余量）；低于余量拒新会话（507）。
- 质量问题增长（按规则分布）。
- UNKNOWN 提交数（发布与上报页状态分布）。

## 常见故障处置
| 现象 | 定位 | 处置 |
|---|---|---|
| Agent 心跳失败 | 设备采集页离线 | 检查网络/令牌；`agents/{id}/commands` 下发 rescan |
| 上传 409 chunk conflict | Agent local_issue `chunk_conflict` | 源文件被改写（A06）→ 新扫描版本重传 |
| verify FAILED（FILE_HASH_MISMATCH） | 文件资产页 QUARANTINED | 传输损坏：同一幂等键重建会话重传；隔离区核对 |
| 条码 0 候选 | 质量队列 BARCODE_NOT_FOUND | PIS 补录后触发 `resolve_waiting` 或页面「重新评估」 |
| 条码多候选 | 质量队列 SOURCE_AMBIGUOUS | 关联复核页人工选择（必填理由；不改HIS/PIS） |
| 提交 UNKNOWN | 发布与上报页 | 「更正/重试」走 query_unknown；不得手工新建提交 |
| 回执缺失 | 对账页 NO_RECEIPT | 保持待确认；按对账补偿策略处理 |
