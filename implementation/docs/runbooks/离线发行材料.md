## 目标机安装步骤（Windows 服务器示例）

1. 安装 CPython 3.14 64 位到固定路径。不要用 3.12 去装当前 wheelhouse。
2. 复制发行目录。在 `implementation` 下执行：
   `python -m pip install --no-index --find-links deploy/offline/dist/wheelhouse -r deploy/offline/dist/requirements.lock.txt`
3. 内网单机按 [deploy/intranet/README.md](../../deploy/intranet/README.md) 设置令牌并运行 `start.ps1`。
   它使用 SQLite，并把对象卷放到 `var/intranet/volume1`。PostgreSQL 要另行配置 `BLYB_DATABASE_URL`，且尚未实测。
4. 扫描电脑的计划任务脚本是 `deploy/windows/install-agent-service.ps1`。它不是 Windows SCM 服务。
5. 控制台由 core-api 托管 `apps/admin_web/dist`，地址是 `http://<主机>:8000/ui/`。

## 升级（expand-contract）
1. 备份（见备份runbook）→ 2. 停worker → 3. 部署新代码 → 4. 启动自动跑新增迁移（仅加列/加表，
   收缩列延后两版）→ 5. 回滚=恢复备份+旧代码（外部平台提交不自动回滚）。
