## 平台依据

- [官方uploadretail API页](https://developer.alibaba.com/docs/api.htm?apiId=52553)：
  timestamp为GMT+8，允许最大误差10分钟；未要求客户端必须运行NTP守护进程。
- 同页业务必填为bill_code/bill_time/bill_type/ref_user_id/trace_codes；bill_code唯一。
  bill_type示例321而说明仍列323，冲突继续如实保留；不自行宣称平台已裁决。
- 页面“不需要授权”对应OAuth session参数可不传，不代表无需企业授权APPKEY/医疗机构权限包。
- [本地官方指南快照](../drug-trace-firstbill-exec-20261021/reference/official-guide-202601.md)
  的前期步骤仍要求企业入驻且服务期内、企业授权AppKey和医疗机构权限包。
  此次语雀在线页面工具无法读取，未声称在线指南已再次读成功；以上快照与可访问官方API页分别注明来源。
- 医院正式CA是院内两机的身份/信任部署要求；不是上传业务字段。延期正式CA不代表可跳过TLS/mTLS验证。
