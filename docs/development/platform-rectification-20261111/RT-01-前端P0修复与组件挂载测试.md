# RT-01 前端 P0 白屏崩溃清零、前后端契约对齐与组件挂载测试

> 预计工作量：1.5～2.5 小时。依赖：无（第一顺位优先执行）。动生产：否。
> 先完整阅读 [总览与通用铁律](README.md)。

---

## 0. 背景与目标

独立代码审计发现：虽然前端 `npm run build` 通过、51 个纯函数测试全绿，但由于之前盲写页面时**弄错了公共组件的 Props/Slots/Events、路由映射键名和后端返回字段名**，实际打开浏览器会出现：
- 默认首页 `/dashboard` 直接抛 `TypeError: Cannot read properties of undefined (reading 'localeCompare')` **整页白屏**；
- 业务详情页 `TargetDetail.vue` 因 `<Tabs>` 无 `<slot/>` 导致 **7 个页签内容 100% 空白不可见**（含传染病导入和医保联调台）；
- `/system/users` 与 `/targets/inf_cdc_frontend` 路由组件映射为 `undefined` **点击即白屏**；
- 所有页面的 `<PageHeader #actions>` 按钮**全部隐身**；
- 所有 `<Drawer>` / `<Modal>` 点关闭按钮或遮罩 **完全关不掉**；
- 所有 `<StatusTag :status="...">` **全部渲染成 `—`**；
- 新建用户静默丢失业务范围 `target_scopes`、审计 CSV 导出无鉴权头必返 **401**、全部新页面把 UTC 当本地时间显示（慢 8 小时）、圆环图 `<Donut>` 扇区飞出中心、全局 CSS 污染侧栏。

本任务目标：**一次性消灭上述全部 18 项前端 P0/P1 缺陷**，并利用已安装的 `@vue/compiler-sfc` + `vue/server-renderer`（零新依赖！）建立**组件与视图级真实渲染测试**，从根源上杜绝“编译通过但页面空白/崩溃”。

## 2. 详细实施步骤（必须逐项按顺序执行，不得遗漏）

### 步骤 1：修复路由注册断路（`src/router/menu.ts` & `src/router/index.ts` & 异常页）

1. 检查 `src/router/menu.ts` 与 `src/router/index.ts`：
   - **问题 A**：`menu.ts` 中用户管理路径是 `/system/users`，`index.ts` 用 `it.path.replace(/^\//, '')` 得到 `'system/users'`，但 `map` 里的键名是 `'users'`，导致 `component: undefined`！
   - **问题 B**：`menu.ts` 中写了 `{ path: '/targets/inf_cdc_frontend', label: '传染病上报' }`（甚至若还有 `/targets/medins_emr_sd`），`index.ts` 把菜单项全部生成了静态路由，但 `map` 里根本没有 `'targets/inf_cdc_frontend'`，生成了一条 `path: '/targets/inf_cdc_frontend', component: undefined` 的静态路由，**在 vue-router 中静态路由优先级高于动态路由 `/targets/:code`**，导致所有进入传染病详情的跳转全部白屏！
   - **修复方案**：
     * 在 `menu.ts` 的 `MenuItem` 接口增加可选字段 `view?: string`（指定对应视图组件名）和 `targetScope?: string`（用于按用户 `target_scopes` 过滤菜单，如 `/drugtrace` 设 `targetScope: 'drug_trace_alihealth'`，`/targets/inf_cdc_frontend` 设 `targetScope: 'inf_cdc_frontend'`，`/targets/medins_emr_sd` 设 `targetScope: 'medins_emr_sd'`）。
     * 在 `index.ts` 生成路由时：**凡是已被动态路由 `/targets/:code` 覆盖的路径（即 `it.path.startsWith('/targets/')`），跳过静态路由重复注册！** 其余菜单项按 `it.view ?? it.path.replace(/^\//, '')` 查找 `map`（并把 `'system/users': () => import('../views/Users.vue')` 显式加入 `map`）。
     * **加硬断言**：在 `index.ts` 构造完 `routes` 后遍历检查：除 `redirect` 路由外，若任何路由 `!r.component`，立即 `throw new Error('Route missing component: ' + r.path)`！这样未来任何人写错路径都会在启动/测试时立刻报错。
2. 修改 `src/views/Forbidden.vue` 和 `src/views/NotFound.vue`：把“返回总览/返回首页”链接从 `/overview` 改为 `/dashboard`。
3. 修改 `src/utils/menu.ts` 的 `filterMenuByRoles(menu, roles, scopes?: string[])`：
   - 当传入 `scopes`（从 `localStorage.getItem('blyb.scopes')` 读取，`platform_admin` 或包含 `'*'` 时不限制）且菜单项声明了 `targetScope` 时，若 `targetScope` 不在 `scopes` 内则隐藏该菜单项。
   - 在 `src/api/auth.ts` 登录成功与 `src/App.vue` 挂载调用 `currentUser()`（`/api/v1/auth/me`）返回后，**同步刷新 `localStorage` 中的 `blyb.roles` 与 `blyb.scopes`（`me.target_scopes`）及响应式状态**，解决管理员改角色/范围后前端侧栏不刷新的问题。

### 步骤 2：修复公共组件契约错配（`Tabs` / `PageHeader` / `Drawer` / `Modal` / `StatusTag` / `ErrorState`）

1. **`src/components/Tabs.vue`**：
   - 在 `<div class="tabs">...</div>` 下方增加默认插槽 `<slot />`！这样无论是 `<Tabs v-model="tab" :tabs="..."><div v-if="tab==='a'">...</div></Tabs>`（包裹写法）还是自闭合 `<Tabs ... />`（并列写法）都能 100% 正常渲染！
2. **`src/components/PageHeader.vue`**：
   - 在右侧操作区同时渲染具名插槽与默认插槽：`<div class="ph-actions"><slot name="actions" /><slot /></div>`，让 `<template #actions>` 和默认插槽写法全部可见！
3. **`src/components/Drawer.vue` 与 `src/components/Modal.vue`**：
   - 当前关闭时只 `emit('update:open', false)`，而新页面大量写了 `@close="xxx = false"` 或 `:open="..." @close="..."`。
   - 在两者的关闭函数 `close()`（点击 ✕、点击遮罩、按 Esc 键）中**同时触发两个事件**：`emit('update:open', false); emit('close')`（在 `defineEmits` 中声明 `close` 事件）。同时把新页面里的 `:open="x" @close="x=false"` 也规范化或验证双兼容。
4. **`src/components/StatusTag.vue` 与 `src/utils/status.ts`**：
   - `StatusTag.vue` 增加可选 prop `status?: string`（兼容 `:bucket`、`:state`、`:status` 三种传参，优先级 `bucket || state || status`）。
   - 在 `src/utils/status.ts` 中补齐所有后端实际枚举的中文标签与颜色映射（严禁落成未知 `'—'`）：
     * 生命周期 `TargetLifecycle`：`PRODUCTION`（正式运行/success）、`PILOT`（试点运行/info）、`MOCK_ONLY`（仅Mock/mock）、`DEVELOPING`（开发中/warning）、`PLANNED`（已规划/muted）、`SUSPENDED`（已暂停/warning）、`RETIRED`（已下线/muted）。
     * 运行形态 `TargetRuntimeKind`：`PLATFORM`（平台托管/info）、`EXTERNAL`（外部程序/warning）、`MANUAL`（人工上报/muted）。
     * 唯一推送方 `sole_pusher`：`CONFIRMED`（唯一已确认/success）、`UNCONFIRMED`（待确认/warning）、`CONFLICT`（存在双推/danger）。
     * 调度运行状态 `ScheduleRun`：`QUEUED`（排队中/info）、`RUNNING`（运行中/info）、`SUCCEEDED`（成功/success）、`FAILED`（失败/danger）、`TIMED_OUT`（已超时/danger）、`STALLED`（疑似卡死/danger）、`SKIPPED_OVERLAP`（防重跳过/warning）、`SKIPPED_BLACKOUT`（维护窗跳过/muted）、`MISSED`（错过跳过/warning）、`CANCELLED`（已取消/muted）。
     * 告警状态与级别：`OPEN`（未处理/danger）、`ACKED`（已确认/warning）、`RESOLVED`（已恢复/success）；`CRITICAL`/`critical`（严重/danger）、`WARN`/`warn`/`warning`（警告/warning）、`INFO`/`info`（提示/info）。
     * 账号与联调：`ACTIVE`（正常/success）、`LOCKED`/`DISABLED`（已锁定/danger）；`PASS`（通过/success）、`FAIL`（未通过/danger）、`ERROR`（异常/danger）、`MANUAL_OBSERVATION`（人工回填/info）。
5. **`src/components/ErrorState.vue`**：
   - 增加可选 prop `compact?: boolean` / `small?: boolean`（支持卡片内紧凑展示）；当父组件未传 `@retry` 监听器时隐藏“重试”按钮（或父组件 `Dashboard.vue`、`TargetDetail.vue`、`Alerts.vue` 全部补绑 `@retry` 对应刷新函数）。
