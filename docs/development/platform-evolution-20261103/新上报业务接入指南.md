# 新上报业务接入指南（LT-09）

每个新上报需求按以下步骤接入；每节给出**要做什么/产出文件/检查项**。
配套脚手架：`python scripts/new_report_target.py`（幂等；已存在不覆盖；
dry-run 零写入；路径越界拒绝）。

## 1. 需求登记
- **做**：ReportTarget 建条目（lifecycle=PLANNED；脚手架自动处理或 API/种子）；
  规范原件放 `数据上报/<编号、业务名>/`；README 用模板建。
- **产出**：目录条目 + 原件 + README。
- **检查**：原件 sha256 已登记（Profile 引用）；README 六要素齐（接口/代码/
  链路/凭据位置/部署证据/下一步）。

## 2. 判定运行形态
- **做**：按决策表选 mode 与 runtime_kind——对方有 HTTP 接口→PUSH/PLATFORM；
  对方来采→PULL；已有稳定外部程序→EXTERNAL（先只读台账，LT-05 模式）。
- **检查**：形态写入 README；EXTERNAL 需同时规划 state 副本导入。

## 3. 契约化
- **做**：`tools/spec_extract.build_profile`（docx）或 `csv_profile`（清单 CSV）
  生成 `profiles/<code>/`；人工复核 EXTRACTION_REPORT 待核项 → status=REVIEWED。
- **产出**：transactions/fields/dicts/samples（全合成值）/报告。
- **检查**：泄漏检查脚本命中 0；未知项（签名/长度单位）显式 UNCONFIRMED。

## 4. 数据源
- **做**：SourceProfile 或视图 DDL 提案（**交 DBA**，AI 禁 DDL）；映射用
  mapping_engine 声明式规则；谓词避免拼接串/函数包裹索引列（view-tuning 教训）。
- **检查**：视图列契约与 Profile 对齐；索引可用性 EXPLAIN。

## 5. 目的地
- **做**：优先 generic_http_json 纯配置接入；协议特殊（签名/加密/SOAP）才写
  专用适配器并实现 DestinationAdapter。
- **检查**：is_mock 目的地只指本机回环；真实发送必须过 assert_target_can_send_real
  + real_send_evidence_ref。

## 6. 回执与状态
- **做**：平台返回码 → REPORT_BUCKETS 映射表；**必须覆盖未知**——网络异常/
  服务端异常耗尽重试一律 UNKNOWN，不得当失败重发。
- **检查**：Mock 证据单列（evidence_kind）；ACCEPTED≠CONFIRMED。

## 7. 幂等与次序
- **做**：idempotency_key=业务主键+版本/操作时间；更正=新 revision；重试=同
  revision；旧版本显式拦截。
- **检查**：同版本重发幂等测试；跨目标拒绝测试。

## 8. 调度与告警
- **做**：schedule 建立后 **enabled=False**；默认 4 条告警规则（NO_SUCCESS_WITHIN/
  UNKNOWN_OVER/BACKLOG_OVER/REJECT_RATE_OVER，notify=file_default）。
- **检查**：种子后查询确认 enabled=False；系统任务不在生产自动启用。

## 9. 测试
- **做**：Mock 行为档、契约校验、映射等价（真实分支非 Mock 分支）、闸门拒绝
  真实发送。
- **检查**：新测试 ≥25；全量回归无新增失败。

## 10. 上线闸门
- **做**：MOCK_ONLY→PILOT（用户授权+唯一推送方 CONFIRMED+real_send_evidence_ref）
  →PRODUCTION；回退路径预先写清（保留新账）。
- **检查**：每步留审计；不能仅靠改 Target 字段获得真实发送。

## 11. 文档同步
- **做**：业务 README、数据上报索引、STATE/BACKLOG/HANDOFF、四类实施文档。
- **检查**：project_docs.py check 无新增断链。
