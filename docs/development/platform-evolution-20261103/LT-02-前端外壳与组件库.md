## 0. 为什么做

现前端（`implementation/apps/admin_web/`）只有 Vue 3.5 + vue-router 4.5，没有任何 UI 库、组件目录、状态管理；
19 个菜单平铺不分组不按角色；样式全挤在 `App.vue`；页面普遍 `JSON.stringify` 直出、请求失败无提示。
后续 LT-06/07 要加十几个页面，**必须先有统一外壳和可复用组件**，否则会再堆出十几个各写各的页面。

**硬约束：不得 `npm install` 任何新包**（离线、不引新依赖）。所有组件、图表手写（Vue SFC + CSS + SVG）。

## 1. 交付物

1. 设计令牌与全局样式：`src/styles/tokens.css`、`base.css`、`components.css`，`App.vue` 中的全局样式迁出。
2. 组件库 `src/components/`（≥16 个，清单见步骤 3），每个组件顶部注释写用法示例。
3. 类型化 API 层 `src/api/`：`http.ts`（含 PUT/DELETE、统一错误对象、可取消）、`types.ts`、按领域拆分的端点模块；**旧 `src/api.ts` 保留并改为从新层 re-export**，保证 DrugTrace 等旧页面零修改可用。
4. 新布局：分组侧栏（可折叠）+ 顶栏（当前用户、角色、改密、退出、环境标识）+ 面包屑 + 内容区；窄屏（<900px）侧栏抽屉化。
5. 路由重构：菜单配置集中在 `src/router/menu.ts`（分组、图标字符、角色、是否 Mock 标识）；路由守卫（未登录→登录页；角色不足→403 页）；404 页。
6. 用新组件改造 8 个简单页面（清单见步骤 6），**不改它们调用的 API**。
7. `DrugTrace.vue` 不改内部，只保证在新布局里样式正常。
8. 前端单元测试：用 `node --test` 测纯 TS 工具函数（时间格式、字节格式、状态映射、菜单角色过滤），≥20 个用例。
9. `npm run build` 退出码 0；`node --test (Get-ChildItem -LiteralPath tests -Recurse -File -Filter '*.test.mjs' | Select-Object -ExpandProperty FullName)` 全过。

### 步骤 4：工具函数 `src/utils/`（这些要写单测）

- `time.ts`：`formatHospitalTime(iso)`（固定 +08:00，不依赖浏览器时区；非法输入返回 "—"）、`relativeTime(iso, now)`（"3 分钟前"）、`daysAgoRange(n)`。
- `bytes.ts`：`formatBytes(n)`（1024 进制，保留 1 位小数，null→"—"）。
- `status.ts`：`BUCKET_LABEL`、`BUCKET_TONE`（与后端 `REPORT_BUCKETS` 一一对应：PENDING→info、SENDING→info、ACCEPTED→warning、CONFIRMED→success、PARTIAL→warning、REJECTED→danger、UNKNOWN→danger、NOT_REPORTABLE→muted），`lifecycleLabel()`（PLANNED 已登记 / DEVELOPING 开发中 / MOCK_ONLY 仅 Mock / PILOT 试点 / PRODUCTION 正式 / SUSPENDED 暂停 / RETIRED 下线）。
- `menu.ts` 中的 `filterMenuByRoles(menu, roles)`：`platform_admin` 看全部；其余按 item.roles 交集；空分组隐藏。
- `rate.ts`：`successRate(buckets)` = CONFIRMED / (CONFIRMED+REJECTED+PARTIAL+UNKNOWN)，**分母为 0 返回 null（显示"—"），绝不显示 100%**；UNKNOWN 单列。

测试放 `tests/utils.test.mjs`。因为 node 不能直接跑 TS：把这几个 utils 写成**不依赖 Vue 的纯 TS**，
测试前用已有依赖编译——做法二选一并在交接写明：
(a) 测试文件里用 `import { transform } from 'esbuild'`（esbuild 是 vite 的依赖，`node_modules/esbuild` 已存在则可用；先 `Test-Path node_modules/esbuild` 确认）即时转译后 `import()`；
(b) 参照现有 `tests/drugTraceDisplay.test.mjs` 是怎么测 `drugTraceDisplay.ts` 的，照同一方式。**优先 (b)**。
