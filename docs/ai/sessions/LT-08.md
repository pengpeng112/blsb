## 三、每单执行路径（步骤 1 交付；标注：频次/commit/会话/额外 SELECT）

```
worker tick → claim_job（SELECT 待处理 job 全量 .all() + UPDATE + commit【每片 1 commit】）
→ plugin._j_collect（oracle: page_limit=25, max_pages=1 → JobYield 让出重排）
  ├─ 复核 run/connector/ConfigRevision（SELECT ×3）
  ├─ LeaseGuard（20s 独立会话续租；progress_hook=guard.check）
  └─ service.run_collection
      ├─ PENDING→RUNNING + fence(UPDATE job) + commit【commit 1/片】
      ├─ ingest.collect_window
      │   ├─ gate()：独立只读会话读 run+connector(+oracle 证据)【基线 2 会话 2 commit；
      │   │   O3 后 1 会话 1 commit】×每片前后各一次
      │   ├─ _drain_retry_ledger（SELECT 重取账本全量）+ commit【1/片】
      │   ├─ poll_bills（源查询 1/页）
      │   ├─ 每单：read_bill_whole = bill_codes（源查询；>200 码翻页）+ bill_header 复核
      │   │        （源查询）→ 每单 2 次源端往返【O4 批量化：每页 2 条】
      │   ├─ 每单：import_bill（基线 3 SELECT[bill 自然键(无复合索引!)/revision/
      │   │        source_record] + INSERT[rev/码索引×N/SRR/raw_payload JSON 双写/
      │   │        issues×N/outbox] + DELETE quality_issue[(tenant,state) 索引扫 OPEN 全量]
      │   │        【O1 后 3 SELECT/页；O2 后新单 0 DELETE】）
      │   └─ checkpoint+progress+fence+commit【页级原子，1/页】
      └─ 终态裁决：_fresh_run_state（独立会话）+ refresh + fence + commit【1/片】
→ JobYield → yield_job（available_at+1s）→ 下片与 prepare job 同优先级 FIFO 交错
→ 次 tick：drain_outbox 每事件 1 commit + BILL_INGESTED(VALID)→enqueue prepare
   → prepare job：claim commit + 冻结包/Submitting/Item 插入 + handler commit
     + finish_job commit + Operation 落账 commit ≈ 每有效单 +4~5 commit【实测 +2.44/单】
```

## 四、计划偏差

1. 基线测量方式：工作区有大量未提交 W 系列改动，`git stash` 到 HEAD 会丢既有改动（实测
   HEAD 上 12 个 domain 测试失败）——改为在 `var/lt08-baseline-code/` 重建优化前代码
   （三文件用会话初原文、service.py 反转本会话编辑），并用黄金快照验证基线忠实性
   （`python ../var/lt08-baseline-run.py check` 通过）。该目录为测量工件不入库。
2. PostgreSQL 组：本机 Docker daemon 不可用 → 按任务书"若本机有"条件跳过，PG 验证写入
   报告 §六部署建议（生产计时方案）。
3. `--after-worker` 预载库大组测量（500 单全链路 prepare）超过 20 分钟被主动终止——
   其 commit 放大结论已由 200 单小组实测（+2.44/单）支撑；未留完整 JSON。
4. bench 生成器初版三处缺陷（record_id 每单不唯一/updated_at 越窗/bad-qty 误改全局行，
   另预载与计时单号空间相撞）在基线测量前修复并重建预载库；修复只影响合成数据，不影响
   产品代码与黄金（黄金在修复后生成）。
