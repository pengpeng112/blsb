## 1. 改了什么（按任务书）

### S01/S02 调度生命周期
- `plugins/scheduling/scheduler.py`：
  - `mark_run_started(db, job, now=None)`：仅处理 payload 带 `schedule_run_id`
    的 Job；绑定校验 run.tenant_id==job.tenant_id、run.job_id==job.id、
    payload.schedule_id==run.schedule_id（错绑定返回 None 不写库）；首次开跑
    条件 UPDATE（started_at IS NULL）写 RUNNING+started_at+deadline=
    start+max_runtime_seconds；重复领取幂等（保留首次 started_at/deadline，
    不无限延长总预算）；TIMED_OUT/STALLED 不洗回 RUNNING。
  - `finalize_run`：耗时=首次执行→最终结束墙钟（含重试等待、不含排队，
    不足 1 秒允许 0）；`was_timed_out`/`was_stalled` 按 observed 历史与当前
    状态分立保留；历史缺 started_at → duration=None+`started_at_unknown`
    （不伪造 started_at=ended_at）；终态幂等（重复调用不再变化）。
  - `_record_run` 增加 now/result_summary 参数；入队时刻 deadline 按 now 起算
    （观测锚点；首次开跑重置为执行 deadline）。
- `apps/worker/engine.py`：`_run_due_jobs` 在 handler 前
  `_mark_schedule_run_started`（**领取后的独立事务 commit**——claim_job 自身
  commit 的既有约定不改，崩溃窗口=claim 提交后 mark 前，由租约过期抢占+
  mark 幂等恢复，测试如实覆盖该窗口）；success/exception/RequestDeferred 三
  分支统一为 finish_job True 后 `db.refresh` 仅持久化 SUCCEEDED/FAILED 才
  `_finalize_operation`（RETRY_WAIT 不回写业务终态；不可把 False 同时当
  "租约过期"和"重试中"——False 路径不回写，True+RETRY_WAIT 也不回写）。
  补 `PluginRegistryAdapter.target_summary`（含 window= 透传）——修复晨报经
  worker 执行时全部落"摘要不可用"的真缺陷。
- `plugins/scheduling/run_guard.py`：QUEUED 或 started_at 为空者跳过 deadline
  检测（排队积压另一观测口径）。

### S03 misfire/事务
- `packages/workflow_core/cron.py`：`to_aware_utc`（naive 按 UTC 绑定、带
  offset 先 astimezone(utc)）；`CronExpr.previous_at_or_before`（<=now 最近
  合法触发，与 next_after 同 matches/366 天上限/aware 校验）。
- `tick` 重写：now 规范 aware UTC；到期时 `future_next=next_after(now)`
  （严格大于 now；366 天无触发则锚定远未来不触发）+条件 UPDATE 抢占后
  `db.expire(sched)` 防陈值；未超 grace 准点执行原 due；超 grace 的 SKIP 记
  **一条** MISSED（result_summary.collapsed_from/to）；RUN_ONCE 补
  `[旧 next_fire_at, now]` 最近合法槽位（语义修订见 §5）；blackout 判定顺序
  =先按选中槽位计划避让、补跑时实际 now 也在窗口→单条 SKIPPED_BLACKOUT 不
  启动补跑（不延后反复补跑）；`{fire_date}/{fire_date_minus_1}` 用选中槽位
  渲染、入队 deadline 从 now 起算；任何一步异常 `db.rollback()` 后 **re-raise**
  （engine 侧 log 后下一 tick 以同一到期指针重试）；两次相同 now tick 不重复
  （future_next > now 保证）。
