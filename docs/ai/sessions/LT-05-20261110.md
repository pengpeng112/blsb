## 错误核查与修订（2026-11-11 用户指令"检查明确错误并修订"，本轮完成）

1. **A05 配额测试脆弱性（断言未削弱）**：原 `margin=free-1024` 依赖"本次请求自身
   DB/WAL 写盘量>1014B"这一非受控条件触发 507（`service.py` usable_free=free-margin），
   本批新增迁移改变库页布局后稳定翻转失败；改为 `margin=free+1024`（usable_free 恒负
   → 507 确定性触发），断言不变、storage 业务代码零改动。共享文档中此前"环境竞态"
   的定性已同步纠偏。
2. **parity 夹具丢失跨表依赖**：逐表独立调用 `run_table` 未共享 `parent_ops`
   （pusher.py:381-384 真实流程是同一 dict 跨表传递），致 exam_item 两侧被跳过、
   shim 回填分支无等价证据——改为共享 dict + exam_item 空操作人，等价覆盖更强。
3. **悬空引用**：test_ops_api PG 测试引用不存在的 `plugins.scheduling_test_helpers`
   （被 skipif 掩盖）——删除。
4. **导入冲突静默丢弃**：同来源同位置 digest 不一致时仅置局部变量未入报告（spec
   要求显式待核）——conflicts 计数入 stats 与 batch.report（含待核说明，无原文），
   新增测试证明。
5. **rows_read 计数不一致**：解析级被拒行未计入 rows_read——修正（rows_read ⊇
   rows_rejected）。
6. **R01 收紧**：调度 API 新建强制 enabled=False（原 body 可带 True 直接生效）；
   PUT 忽略 enabled（启停必须走 enable/disable 端点留 reason+审计）。
