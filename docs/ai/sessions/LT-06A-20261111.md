## 关键语义（复核/交接要点）

1. **范围判定**：`kind != "user"` → 不受限（机器 token 零改变）；user+platform_admin
   → 不受限（管理需要）；其余按 target_scopes（["*"] 或 code 集合；[]/None=无业务）。
2. **403 先于 404**：范围校验先于存在性——未授权与不存在同响应，防存在性泄露。
3. **最后管理员保护**：同一 subject 行锁串行化并发移除（PG 下即行级互斥；
   SQLite 顺序等效），第二个事务读计数=0 → 409。
4. **审计兼容**：action 保持精确匹配（旧语义），前缀走新参数 action_prefix；
   cursor 分页复用 _keyset_page（cursor=显式值时响应为 dict 形状——与旧版一致）。
5. **路由顺序**：`/api/v1/audit/export` 必须先于 `/api/v1/audit/{event_id}` 注册，
   否则 "export" 被当 id → 404（本轮发现并修正）。
