# 独立任务交接模板

复制到 `docs/ai/sessions/TASK-ID.md`；一个任务一个文件，保持可审查记录。

```text
任务ID/起止时间：
用户目标：
工具/真实模型（不知道写unknown）：
协作session_id：
源码/库版本基线或恢复快照：
修改范围/文件：
实现后的行为：
数据库编号迁移/历史数据处理：
真实验证：命令、工作目录、退出码、结果、证据路径
未执行验证及原因：
发现的问题（已修复也保留）：
已更新的STATE/BACKLOG/业务详细文档：
尚未完成的任务/失败：
下一步精确函数/文件/命令：
结果：completed / handed_off / cancelled
```

不要写令牌、连接密码、患者完整号码或原始敏感报文。完成声明必须与实际验证范围一致。
